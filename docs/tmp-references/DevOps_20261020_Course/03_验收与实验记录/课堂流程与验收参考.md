# 课堂流程与验收参考

## 授课顺序

1. E5：A 采集系统调用和 Make 声明，判断 MD/RD；B 取得缺失 make 的构建日志，生成提示并保存修复候选。
2. E6：A 自动检测并完成修复复检；B 自动执行两轮构建和程序验证。
3. E7：运行测试矩阵，接入 CI，演示失败拦截和修复后恢复。
4. 按验收清单展示报告、日志、代码和 CI 记录。

安装工具、拉取基础镜像和 GitHub 登录安排在课前完成。课堂按 E5、E6、E7 三份 PPT 顺序进行，操作命令以学生实验包 docs 为准。

## 核对结果

|项目|预期结果|
|---|---|
|A 原始样例|MD：main.o → config.h；RD：main.o → unused.h|
|A 修复后|只有 Makefile 改变，findings=[]|
|A 完整门禁|服务测试及七次实际运行全部通过|
|B 初始构建|make not found，失败分类 MISSING_MAKE|
|B 修复后|build=0，运行同一 image_id，exit=0，stdout 为 hello E3|
|B 完整门禁|服务测试及五个场景全部通过，超时容器已清理|
|CI 失败|PR 为 BLOCKED，普通合并命令被策略拒绝|
|CI 恢复|最新提交检查通过，PR 合并成功|

学生包服务测试数：A 15 项、B 24 项；加入并修复门禁测试后，A 16 项、B 25 项。A 独立判定测试另有 6 项。

## 文件使用

05_验收清单.md 用于逐项检查交付。06_常见问题.md 用于现场排错。本次流程与结果.md 记录完整实验过程。实验记录/ 保存各阶段报告、日志和 CI 文件，供查阅和课堂演示。
