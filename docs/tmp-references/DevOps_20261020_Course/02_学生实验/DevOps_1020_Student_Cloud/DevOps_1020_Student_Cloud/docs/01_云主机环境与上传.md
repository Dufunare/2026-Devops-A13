# 云主机环境与上传

## 服务器与工具

实验在本组 Ubuntu 云服务器上进行。使用 SSH 登录，安装 Git、Python、Make 和 Docker。

服务器需要访问 Docker Hub、软件源、PyPI 和 GitHub。B 组通过 `/var/run/docker.sock` 使用服务器上的 Docker。

## 1. 登录和上传

用 SSH 客户端登录云服务器。登录信息填写云平台提供的服务器地址、用户名和密码或密钥。

用 SFTP 或 WinSCP 将 `DevOps_1020_Student_Cloud.zip` 上传到服务器用户主目录。

SSH 登录后，整块复制（已有依赖时可跳过安装）：

```bash
sudo apt-get update
sudo apt-get install -y unzip git make python3 curl ca-certificates gh
unzip -n ~/DevOps_1020_Student_Cloud.zip -d ~/devops-course
cd ~/devops-course/DevOps_1020_Student_Cloud
ls
```

`unzip -n` 保留目录中已有的文件。

## 2. 检查 Docker

整块复制：

```bash
docker version
docker compose version
docker buildx version
docker run --rm hello-world
```

预期：`docker version` 显示 Client 和 Server，最后一条命令输出 `Hello from Docker!`。已有 Docker 时跳过下一节。

## 3. 安装 Docker

尚未安装 Docker 时，整块执行：

```bash
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
sudo tee /etc/apt/sources.list.d/docker.sources > /dev/null <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc
EOF
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo systemctl enable --now docker
sudo usermod -aG docker "$USER"
```

退出 SSH 后重新登录，检查用户组和 Docker：

```bash
id -nG
docker version
docker run --rm hello-world
```

gcc、make、strace 等构建工具已包含在服务镜像中。

整块复制：

```bash
docker pull python:3.13-slim@sha256:70729b46c69b4f1e97c4822c1af3df53a1476cf5ddc6c087c0c10bc3a5678c2f
docker pull python:3.13-slim@sha256:f82c96458eedc847b233e582eb31336f4954b39cae020b6dcf5b3ed0e5cbcd74
docker pull docker:28.5.1-cli@sha256:9190b0613792e658a7783cf14b2d5ace5941bb68ede7276922ea36ee457d76ad
```

镜像拉取完成后，进入对应组的操作指南，构建服务镜像并运行测试。
