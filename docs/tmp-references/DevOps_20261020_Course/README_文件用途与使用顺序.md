## 使用顺序

1. 课前将 02_学生实验中的 ZIP 发给学生，完成上传、环境检查和镜像构建。
2. 按 E5、E6、E7 顺序使用三份 PPT。讲稿保留在各页备注中。
3. 学生按分组阅读 A 或 B 操作指南，再完成 CI 和提交报告。
4. 使用验收清单核对结果，现场问题查常见问题。
