按《课程原始要求》E7 行：A 组验证检测证据与正确性；最低证据为**单元测试、CI 门禁、结果数据**。E7 PPT 第 20 页及实验包验收清单要求测试日志、`gate-result.json`、`results.csv`、CI 正常/失败/修复和 main 保护记录；并未独立明确“完成 Github Actions 真实运行后，还必须额外在课程云主机重复执行一遍”。
