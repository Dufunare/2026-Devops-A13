- **修复范围仅 `toml.o`**：`remaining_md=[]` 指的是 profile 目标 `toml.o` 的缺失依赖已消除。
- **完整 recheck 仍保留 `MISSING(toml_json, toml.h)`**：`toml_json` 在链接命令中内联编译 `toml_json.c`，该头文件依赖不在本工具修复范围，已在 `final-full/findings.json` 中单列。
